# Virtual Pet

Mascota virtual creada por **Facundo Bangher**.

Elegí un huevo de dragón, pájaro, lagarto o tortuga, hacelo nacer y cuidalo para que crezca: darle de comer, bañarlo, jugar, hacerlo dormir y darle el remedio cuando se enferma. Tiene niveles del 0 al 100, logros, álbum de fotos, accesorios, fondos para el cuarto y seis minijuegos (dos se desbloquean con monedas).

## Jugar en el celular

Abrí la página del juego (GitHub Pages de este repositorio) y:

- **Android (Chrome):** menú ⋮ → *Instalar app*.
- **iPhone (Safari):** Compartir → *Agregar a pantalla de inicio*.

Después de la primera vez funciona sin internet. La partida se guarda en el celular.

Si te queda poca batería, en *Más → Ajustes* está el **modo ahorro** (también se prende solo con menos del 20 %).

Para ver la tienda con compras de prueba (no cobra nada), agregá `?tienda=demo` al final de la dirección.
