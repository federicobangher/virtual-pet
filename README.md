# Virtual Pet

Mascota virtual creada por **Facundo Bangher**.

Elegí un huevo de dragón, pájaro, lagarto o tortuga, hacelo nacer y cuidalo para que crezca: darle de comer, bañarlo, jugar, hacerlo dormir y darle el remedio cuando se enferma. Tiene niveles del 0 al 100, logros, álbum de fotos y cuatro minijuegos.

## Jugar en el celular

Abrí la página del juego (GitHub Pages de este repositorio) y:

- **Android (Chrome):** menú ⋮ → *Instalar app*.
- **iPhone (Safari):** Compartir → *Agregar a pantalla de inicio*.

Después de la primera vez funciona sin internet. La partida se guarda en el celular.
